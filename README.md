# Himalayan Expeditions ETL Project

ETL python project using expedition records from the Nepal Himalaya (1905-2019).

**Dataset:** https://github.com/rfordatascience/tidytuesday/tree/main/data/2020/2020-09-22


## Files
- `data/raw/peaks.csv` - 468 peaks (height, first ascent)
- `data/raw/expeditions.csv` - 10,364 expeditions (year, season, result, deaths, oxygen)
- `data/raw/members.csv` - 76,519 members (age, sex, citizenship, role, success, death)
- `notebooks/Extraction_and_EDA.ipynb` - extraction and EDA

## Done so far
- Phase 1: Extraction
- Phase 2: EDA (basic exploration, data quality checks, exploratory analysis)

Cleaning, database and SQL reports come next.
